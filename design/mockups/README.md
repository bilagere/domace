# Domaće – Visuelle Referenzen

Die Bilder in diesem Ordner sind die verbindliche visuelle Referenz für das Projekt.
Sie leiten Farbklima, Typografie, Bildsprache, Abstände, Komponenten und die ruhige
redaktionelle Gestaltung an. Sie werden nicht als Produktionsbilder auf der Website
ausgeliefert.

Die umgesetzten Seiten dürfen eigenständig und responsiv bleiben; maßgeblich ist der
Charakter des Designsystems, nicht eine Pixelkopie der Mockups.
